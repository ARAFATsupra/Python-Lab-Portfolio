## Topics Covered

### Core Python Basics
- Variable declaration, data types, and type sizes
- Arithmetic operations and mathematical functions
- Swap operations (with and without a third variable)
- Increment and decrement simulation

### Control Flow
- If, elif, else conditionals
- Leap year checker
- Grade calculator
- Character type detection (uppercase, lowercase, digit, special symbol)
- Divisibility checks

### Loops
- While loops and for loops
- Digit counter
- Multiplication table generator
- Pattern printing (triangular asterisk patterns)
- GCD (Greatest Common Divisor) finder

### Functions
- User-defined functions for arithmetic operations
- Even/odd checker using functions
- Factorial calculator (recursive)
- String word counter
- String reversal function
- Value swap by value and by reference

### Arrays and Lists
- Array input, traversal, and element search
- Sum, largest, and smallest element finder
- 2D array (matrix) input and element access
- Matrix addition
- Merge and reverse two lists

### Strings
- String length calculation
- Character type counting (alphabets, digits, special symbols)
- String comparison and concatenation
- Substring extraction and copying
- Reverse string display
- Removing digits and special symbols from a string

### Object-Oriented Programming (OOP)
- Classes and objects
- Constructors and instance variables
- Class-based structures for Company, Student, Employee, and Complex numbers
- Methods for reading and displaying object data

### Data Structures
- Singly Linked List creation and traversal
- Node insertion at a specific position in a linked list

### Sorting Algorithms
- Bubble Sort implementation
- Sorting student scores and roll numbers

### Searching Algorithms
- Linear Search
- Binary Search on a sorted list

## How to Run

### Option 1 — Google Colab (Recommended)
1. Open [Google Colab](https://colab.research.google.com/)
2. Click **File** and then **Upload notebook**
3. Upload any `.ipynb` file from this repository
4. Run each cell using the **Run** button or press `Shift + Enter`

### Option 2 — Jupyter Notebook (Local)
1. Install Python from [python.org](https://www.python.org/)
2. Install Jupyter by running this command in your terminal:
   ```
   pip install notebook
   ```
3. Launch Jupyter Notebook:
   ```
   jupyter notebook
   ```
4. Open and run any `.ipynb` file

### Option 3 — Python Scripts
For programs in the PDF, copy any code block into a `.py` file and run it with:
```
python filename.py
```
